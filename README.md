# 🛠️ Sistema de Administração de Loja – C# + Windows Forms

Este projeto é um aplicativo desktop desenvolvido com **C#** e **Windows Forms**, focado na **gestão administrativa de uma loja**. Ele permite o controle de funcionários, produtos, clientes e vendas, com validações automáticas de dados como **CPF** e **CEP**.

## ✅ Funcionalidades Atuais

- 👨‍💼 **Administração de Funcionários**  
  Cadastro, edição e remoção de funcionários com **validador de CEP** integrado.

- 📦 **Gestão de Produtos**  
  Sistema de controle para cadastro e gerenciamento de produtos.

- 🛍️ **Visualização de Compras Realizadas**  
  Acesso ao histórico de compras com dados organizados e detalhados.

- 👥 **Visualização de Clientes**  
  Listagem de todos os clientes cadastrados.

- 🧾 **Realização de Compras**  
  Processo de compra com **validação de CPF e CEP**, garantindo integridade e padronização dos dados.

## 🔮 Funcionalidades Futuras (Backlog)

- 🔁 **Sistema de RMA (Retorno de Mercadoria Avariada)**  
  Controle de trocas, devoluções e garantias com base no código do produto.

- 🎫 **Sistema de Chamados Técnicos**  
  Módulo para abertura e acompanhamento de chamados por produto e cliente.

## 🧰 Tecnologias Utilizadas

- **Linguagem:** C#  
- **Framework:** Windows Forms (.NET Framework)  
- **Banco de Dados:** MySQL  
- **Bibliotecas / Pacotes:**  
  - NuGet para validação de dados (CEP e CPF)
  - Consumo de APIs externas para consulta de CEP (ex: ViaCEP)

## 💻 Requisitos para Execução

- Visual Studio 2019 ou superior  
- .NET Framework 4.7 ou superior  
- Servidor MySQL (local ou remoto)  
- Conexão com Internet (para validação via API)
